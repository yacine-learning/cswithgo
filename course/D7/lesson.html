History

The binary search tree was discovered independently around 1960 by several people: P. F. Windley, A. D. Booth and A. J. T. Colin, and Thomas Hibbard. Hibbard published the deletion method in 1962: replace the deleted key by its successor, the smallest key larger than it. It is still called Hibbard deletion.

The problem it fixes

A hash table finds a key but knows nothing about order: "the smallest key", "everything between 10 and 20", "the largest key ≤ x" all mean looking at every key. A sorted array answers them, but inserting shifts elements.

How it works

Every node has a key, a left subtree with only smaller keys and a right subtree with only larger ones. Search, insert and delete walk one path from the root: O(height). Delete has three cases: no child (remove it), one child (lift the child up), two children (copy the successor's key here, then delete the successor). Inserting keys already sorted gives a tree that is a list, height n: that is what balanced trees (D8) prevent.

Where it is used

  • Ordered maps and sets: Java's TreeMap, C++'s std::map (both balanced, D8).
  • Range queries: "all events between two times".
  • Floor and ceiling lookups: which function contains this address (exercise 2), which interval contains this point.
