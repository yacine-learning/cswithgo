Keep this
  • A graph is nodes and edges between them, directed or not. A tree is a graph with no cycles where each node has one parent.
  • Store it as an adjacency list: map[node][]node. Memory O(nodes + edges), and the neighbours of a node in one step.
  • Much of computing is a graph: packages and their imports, functions and their calls, routers and their links, the pages of the web; outside computing too: road maps, molecules, citations. Dependencies without cycles form a DAG (directed acyclic graph).

The problem

Lists and trees describe things with one order or one parent. Many real relations are not like that: a package imports several others and is imported by several; a function calls others and is called by others; network links connect routers in loops. You need a structure for "who is connected to whom", with any shape.

Where it comes from

Königsberg (today Kaliningrad) was built around two islands linked by seven bridges, and its people wondered whether one could walk across each bridge exactly once. In 1736 Leonhard Euler proved it impossible, by keeping only what mattered: the four land masses as points, the bridges as lines between them. Each land mass touched an odd number of bridges, and a walk that crosses every bridge once can have at most two such points, where it starts and ends. That abstraction, points and lines with everything else removed, is the first theorem of graph theory.

The idea

Edges are what you store. An adjacency list keeps, for each node, its outgoing edges, which is what traversals need (1.4.2). Following an edge backwards ("who imports unicode?") needs the reverse graph, built once by flipping every edge.

Adjacency matrix: the other way to store a graph

An n × n table where cell (a, b) says whether there is an edge. Checking one edge is O(1), but it takes n² cells even when there are few edges, and listing a node's neighbours means reading a whole row. Most real graphs are sparse (a package imports a handful of others, not all of them), so adjacency lists are the usual choice.
