What this project practises
  • Building a tree from flat data, with a map of children per node (1.2.2).
  • Recursion that returns a value up the tree (1.3.1), in post-order (1.3.3): a directory's size needs its children's first.
  • Output in a stable order: sort the children's names, never trust map order.

The situation

A disk is full and you want to know which directory is to blame: that is du -d 1. The input is what find . -type f -printf '%p %s\n' gives: every file with its size. du prints a directory after everything inside it, because it only knows a directory's size once it has added up its contents.
