What this project practises
  • Building a tree from flat data, with a map of children per node (1.2.2).
  • Recursion that returns a value up the tree (1.3.1), in post-order (1.3.3): a folder's size needs its children's first.
  • Output in a stable order: sort the children's names, never trust map order.

The situation

A file system is a tree, but it is often described as a flat list: every file with its full path. Rebuilding the tree from the paths, then adding up sizes from the leaves to the root, is a small model of what a file system does each time it reports how much space a folder takes. A folder's size is only known once everything inside it has been added up: the children come first.
