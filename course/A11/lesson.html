History

Depth-first search is older than computers: in the 19th century the French engineer Charles Pierre Trémaux described a way out of any maze by marking the passages you have walked, published by Édouard Lucas in 1882.

The problem it fixes

Some questions need the whole structure of a graph, not distances: does it have a cycle? Which nodes can I reach at all? In what order must things happen?

How it works

Go as deep as possible along one path; when stuck, back up to the last node with an unexplored edge. Recursion (A2) does the backing up for you. Colour the nodes to find cycles: white (not seen), grey (on the current path), black (finished). Meeting a grey node again means the path has come back to itself: a cycle. O(nodes + edges).

Where it is used

  • The Go toolchain refuses import cycles and prints the cycle (exercise 1).
  • Topological sort (A12) can be done with DFS: a node goes on the list after all its dependencies.
  • Solving mazes, and backtracking (A16), which is DFS over choices.
  • Detecting deadlocks: a cycle in the graph of "who waits for whom".
