History

The notation is older than computers. Paul Bachmann, a German number theorist, wrote O(n) in 1894 for "a quantity of the order of n": the O is for Ordnung. Edmund Landau spread it in 1909. Programmers needed it in the 1960s, when machines differed in speed by factors of a hundred and "it took 3 seconds" said more about the machine than about the algorithm. In 1976 Donald Knuth asked computer scientists to adopt O, Ω and Θ with precise meanings; they did.

The problem it fixes

"Is this fast enough?" depends on the machine, the language and the input. We need a way to compare two algorithms before writing them, and to know what happens when the input grows a thousand times.

How it works

Count the steps as a function of the input size n, keep only the term that grows fastest, drop the constants. Then doubling n tells you the class:

classn doubles, time…example
O(1)stays the samea map lookup
O(log n)+ one stepbinary search
O(n)× 2one loop over the input
O(n log n)a bit more than × 2a good sort
O(n²)× 4two nested loops
O(2ⁿ)squaredtrying every subset

Where it is used

  • Choosing a data structure: a map (O(1)) instead of a slice scan (O(n)) inside a loop turns O(n²) into O(n) (exercise 1).
  • Knowing in advance what is feasible: n² is fine for 1 000 items, hopeless for 10 million.
  • Every other page of this course states its cost this way.
