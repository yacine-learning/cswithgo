History

Breadth-first search was first written by Konrad Zuse in 1945, in his thesis on the Plankalkül language; it was rejected and stayed unpublished until 1972. It was reinvented in 1959 by Edward F. Moore to find the shortest path out of a maze, and in 1961 C. Y. Lee used it to route the wires on circuit boards.

The problem it fixes

"What is the fewest number of steps from here to there?" Following one path deep (A11) may find a long way first and never know a shorter one exists.

How it works

Explore in rings: first every node one step away, then every node two steps away, and so on. A queue (D4) holds the frontier, and a visited set makes sure each node enters the queue once. The first time BFS reaches a node, it has found a shortest path to it, counted in edges. O(nodes + edges). Remember for each node where you came from, and you can rebuild the path.

Where it is used

  • Fewest hops between two machines in a network (exercise 1).
  • Garbage collectors that trace every object reachable from the variables.
  • Web crawlers, and "friends of friends" in social networks.
  • Solving puzzles in the fewest moves: each position is a node.
