History

Allen Newell, Cliff Shaw and Herbert Simon invented linked lists in 1955–56 for their Information Processing Language (IPL), to write the Logic Theorist, often called the first artificial intelligence program. The box-and-arrow drawing of a list first appears in Newell and Shaw's 1957 paper. IPL inspired Lisp, whose name means LISt Processing. Newell and Simon received the 1975 Turing Award, partly for list processing.

The problem it fixes

Inserting or deleting in the middle of an array shifts everything after it, O(n). And an array needs one contiguous block of memory, which early machines rarely had to spare.

How it works

Each element lives in its own node, which points to the next one. Inserting or removing next to a node you already hold is O(1): change two pointers. The price: no indexing (reaching element i walks i nodes), and every step is a pointer jump, unfriendly to the processor's cache. A dummy head node removes the special case of the first element.

Where it is used

  • Go's container/list (a doubly linked, circular list).
  • The LRU cache (D6): a list keeps the order of use, a map finds the node.
  • Inside operating systems: lists of processes, free memory blocks, waiting tasks.
  • Hash table buckets with chaining (D5).
