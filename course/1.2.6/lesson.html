What this project practises
  • A stack to follow nesting (1.2.3): what is open, and in which order it must close.
  • A map to add up by name (1.2.2), and a slice sorted to rank the results (1.2.1).
  • Errors that say where: a line number and what was expected.

The situation

A tracing tool (OpenTelemetry, Jaeger, a CI system's timing log) records when each step of a job starts and ends. Steps nest: the test step runs inside build, which runs inside pipeline. You want to know where the time goes, and you want a broken trace to be rejected with a precise message rather than a wrong report.

10 start pipeline
12 start build
15 start test
41 end test
44 end build
45 start deploy
60 end deploy
61 end pipeline
